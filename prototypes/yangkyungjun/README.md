## 무엇을 검증하는 프로토타입인가

화면 시연이 아니라 **부탁 객체의 스키마와 상태 기계**를 확정하려고 만들었다.
따라서 남는 물건은 `intro-request.js` 와 스펙 문서이고, `index.html` / `app.js` 는 그것이 실제로 돈다는 걸 눈으로 보여주는 장치다.

| 파일 | 역할 |
|---|---|
| `intro-request.js` | **상태 기계 + 검증 규칙.** 순수 함수, 시간은 `now` 인자로 주입. 실제 앱으로 옮겨질 물건 |
| `intro-request.test.js` | checks 22개 (`node --test`) |
| `index.html` · `app.js` | 좌우 분할 데모. 규칙은 한 줄도 들어 있지 않다 |

## 실행

**테스트**

```
cd prototypes/yangkyungjun
node --test
```

레포 루트에서 바로 돌리려면:

```
node --test "prototypes/yangkyungjun/*.test.js"
```

(`node --test prototypes/yangkyungjun` 처럼 디렉터리만 주면 Node 가 그 경로를 모듈로 읽으려다 실패한다. 경로 끝까지 적거나 위 두 형태를 쓴다.)

**화면** — `index.html` 을 더블클릭한다. 서버도 설치도 필요 없다.
(ES 모듈 대신 CommonJS 겸용으로 쓴 이유가 이것이다. ES 모듈이면 `file://` 에서 CORS 로 막혀 서버를 띄워야 한다.)

## 화면 보는 법

- **왼쪽 대문(大門)** — 싱글. 주선자 한 명을 고르고, 7개 항목에 `필수 / 선호 / 상관없음` 등급을 매겨 보낸다. **필수는 2개까지.**
- **오른쪽 사랑채(舍廊)** — 주선자. 받은 부탁을 보고 `찾아볼게요`(확인) · `조금 뒤에`(보류) · `이번엔 어렵겠어요`(종료).
- **아래 마당 — 시간.** `+1일` / `+7일` 로 시계를 돌린다. 만료·쿨다운이 전부 시간 기반이라 이게 없으면 절반을 못 본다.

## 눈으로 확인할 것 (수동 checks)

| # | 해볼 것 | 보여야 하는 것 |
|---|---|---|
| **M1** | 오른쪽에서 `이번엔 어렵겠어요` 클릭 | 왼쪽이 즉시 **"이번엔 닫힘"**. 싱글에게는 거절인지 만료인지 **구분되지 않는다** |
| **M2** | 부탁을 보내고 아무것도 안 한 채 `+7일` | 만료되어 **남은 칸이 돌아온다**. 그리고 같은 주선자에게는 14일간 다시 못 보낸다 |
| **M3** | 세 번째 항목을 `필수`로 찍어보기 | 막히고, **무엇을 양보할지 고르는 일이 이 기능의 핵심**이라고 말해준다 |
| M4 | 사랑채에서 `열어보기` 를 누른 뒤 왼쪽을 보기 | `고치기` 버튼이 사라진다. 주선자가 떠올려 본 수고를 지키기 위해서다 |
| M5 | 부탁을 3건 보내고 네 번째 시도 | 주선자 카드가 전부 잠기고 이유가 뜬다 |

## 주의

- 저장은 `localStorage` 다. `처음부터` 버튼(두 번 클릭)으로 지운다.
- 주선자 3명(김선영·박지훈·이수진)과 싱글 1명은 **가짜 시드 데이터**다.
- 알림은 없다. P0-Beta 로는 필수지만 프로토타입에는 불필요해서 뺐다(스펙 §4).
