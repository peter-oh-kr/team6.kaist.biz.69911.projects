## 프로젝트 소개

사이는 가입한 지인의 초대를 통해 참여하는 소개팅 서비스다. 친구에게 소개받고 싶지만 원치 않는 사람에게 가입 사실이나 프로필이 알려지는 것은 부담스러운 싱글, 그리고 소개할 마음은 있지만 정보 전달과 중간 연락이 번거로운 주선자를 위해 기획했다.

한 사람이 싱글과 주선자를 겸할 수 있다. 당사자가 허용한 범위에서 주선자가 두 사람을 추천하고, 양쪽이 모두 수락하면 대화가 열린다. 지인 관계와 정보 공개 권한을 구분하며, 가입했다고 모든 지인에게 프로필이 공개되는 방식은 지향하지 않는다.

## 기본 이용 흐름

1. 가입한 지인이 초대 링크를 보낸다.
2. 초대받은 사람은 본인인증을 거쳐 가입한다. 회사 메일 인증은 선택이다.
3. 소개받을 사람은 프로필을 작성하고 정보 공개 범위와 주선 권한을 설정한다.
4. 허용받은 주선자가 두 사람을 골라 소개 카드를 보낸다. AI는 비교와 소개말 작성을 보조한다.
5. 두 사람이 각각 수락하면 대화가 열린다. 소개받는 사람도 다른 지인을 초대하거나 주선할 수 있다.

## v1.1의 검증 범위

첫 차별점은 **지인의 초대**다. 초대를 받은 사람이 실제로 참여하는지, 공개 범위를 이해하고 안심할 수 있는지, 주선자가 소개를 보내고 양쪽의 수락까지 이어지는지를 먼저 확인한다. 기존 메신저로 소개할 때보다 어떤 수고가 줄어드는지도 살핀다.

현재는 기획과 화면 프로토타입을 바탕으로 초기 검증을 준비하는 단계다. 초대 방식의 수요와 실제 운영 효과는 검증이 필요하다. **QR 초대, 주선자 동석, 리워드·과금 방식, 지인 연결 거리 제한**은 미결 사항으로 남겨둔다. 서비스 이름도 가칭이다.
